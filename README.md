# 11501 AIOT Socket 聊天室

DEMO影片： [https://youtu.be/PN90WIDVYUQ](https://youtu.be/PN90WIDVYUQ)

學號：114502547　姓名：陳依彤

## 功能
- Server：輸入名稱後開啟聊天室，顯示 IP 與 Port
- Client：輸入名稱、IP、Port 後加入聊天室
- 支援多個 Client 同時連線，訊息會廣播給所有人
- 顯示誰進來、誰離開
- 名稱重複時會被拒絕，需換名稱

## 專案結構
- `app`：Server 端
- `Client`：Client 端
